dsh-session-folders v0.3.1 — 侧栏对话文件夹分组插件
=====================================================

功能：把 DSH 侧栏的对话整理进可嵌套、可配色的文件夹。
右键菜单 / 拖拽排序 / 批量选择 / 文件夹内新建对话 / 重命名 / 删除，一应俱全。

v0.3.1 新增：
- 去掉了侧栏底部单独的那个「批量选择」按钮（界面更干净，入口改到菜单里）
- 文件夹现在也能批量选择：右键文件夹、或点它右边的 ⋯（三个点），
  菜单里选「☑ 批量选择」即可进入；进去后可同时勾选多个文件夹 / 多个对话，
  再一次性「移入」某个文件夹或「删除」
- 批量选择模式下点文件夹行 = 勾选该项（不会误触发折叠/展开）

v0.3.0 新增：
- 侧栏展开文件夹后，里面的对话带竖向导引线；线的颜色跟随文件夹配色，层级一目了然
- 文件夹名字太长时，鼠标悬停可显示全名
- 顶部「新会话」按钮：若存在名为「闲聊」的文件夹，新对话会自动放进它并置顶
  （没有「闲聊」文件夹时不影响原生行为）

安装方法（推荐给朋友的方式）
----------------------------
1. 把本压缩包解压到一个固定位置，例如：
   C:\Users\<你的用户名>\.dsh\external\dsh-session-folders
   （解压后该目录里应直接看到 package.json 和 lib 文件夹）

2. 打开你的 DSH 网页版（http://127.0.0.1:3080），在对话框里粘贴下面这段提示词发给 AI：

   请帮我安装一个本地 DSH 插件。插件目录在：C:\Users\<你的用户名>\.dsh\external\dsh-session-folders
   请用 dev_install_package 工具把它装配到 web profile（幂等，直接执行即可），
   装完告诉我刷新页面。

3. AI 装配完成后，按 Ctrl + Shift + R 强制刷新页面。
   侧栏底部会出现「📁 新建文件夹」，把对话拖进去，或右键对话 → 移动到分组。

使用小抄
--------
- 文件夹行悬停：＋ 在此新建对话 ⋯ 文件夹菜单
- 对话右键 / ⋯：重命名、移动到分组▸、移出分组、批量选择、删除
- 文件夹右键 / ⋯：在此新建对话、新建子文件夹、移动到…▸、批量选择、
  重命名/配色/图标、移到顶层、删除分组
- 拖文件夹：上 1/3 = 排到前面，下 1/3 = 排到后面，中间 = 嵌套进去
- 拖对话到两行之间：插入到该位置
- 批量选择模式：勾选多个对话 / 多个文件夹，一次移动或删除
  （删除分组时，分组里的对话会安全地移回未分组，对话本身不会被删掉）
- 批量「移入」到某个文件夹时，会自动跳过目标自身和它的子文件夹，避免形成死循环

卸载
----
在 DSH 对话框里发：请用 dev_uninject_plugin 卸载 @dsh-external/dsh-session-folders
卸载不会删除你的分组数据（~/.dsh/profiles/web/session-folders.json 保留）。
